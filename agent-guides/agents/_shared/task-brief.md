## Task briefs

Your input may be a **task brief** (conventionally `BRIEF.md`) instead of a
ticket or spec. Its format, and how each agent uses it, is defined in
`agent-guides/agent-interfaces.md` — read that section before working from
one.

The rule that matters most: **when the brief requires behavior a style rule
discourages, the brief wins.** Record it as a brief-required conflict rather
than correcting it or reporting it as a defect. A brief cannot override a
language rule; code that would not compile or run is an open question.
