## Rationale

Initials record who is accountable for a change. Initials an agent invents
record nothing true, so the line is left out.

## Examples

### Good

```text
Returns...... : {.T., NIL} on success
Date......... : 2026-10-13
```

### Bad

```text
Returns...... : {.T., NIL} on success
Author....... : AI
Date......... : 2026-10-13
```
