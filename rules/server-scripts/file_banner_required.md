## Rationale

The banner is the file's contract: what it does, what each parameter means,
and the exact result shape. Callers and reviewers read it before the code.

## Exceptions

Code generated by a tool or agent leaves out the `Author` line (see
`generated_banner_omits_author`).

## Examples

### Good

```ssl
/* ********************************************************************************
Description.. : Records a status change for one sample.
Parameters... : sSampleId - Sample to update
                sStatus   - New status value
Returns...... : {.T., NIL} on success
                {.F., {sCode, sMessage}} on failure
Author....... : ABC
Date......... : 2026-10-13
********************************************************************************;
:PARAMETERS sSampleId, sStatus;
:DEFAULT sSampleId, "";
:DEFAULT sStatus, "";

:RETURN ExecFunction("Samples.WriteStatus", {sSampleId, sStatus});
```

### Bad

```ssl
:PARAMETERS sSampleId, sStatus;
:DEFAULT sSampleId, "";
:DEFAULT sStatus, "";

:RETURN ExecFunction("Samples.WriteStatus", {sSampleId, sStatus});
```
